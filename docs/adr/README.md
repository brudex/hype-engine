# Architecture Decision Records

Use this directory for decisions that future contributors should not have to
rediscover.

Name records with a four-digit sequence and a short title, for example:

`0001-use-versioned-database-migrations.md`

Each record should contain:

```markdown
# Decision title

Status: proposed | accepted | superseded

## Context

What forces and constraints require a decision?

## Decision

What was decided?

## Consequences

What becomes easier, harder, required, or intentionally unsupported?
```

Do not use an ADR for temporary implementation notes or decisions that are
obvious from the code.
