# Hype Engine repository positioning

Prepared 2026-07-29 for the contributor-growth campaign. These values are
ready to apply in the GitHub repository settings; no external setting was
changed by this draft.

## Positioning statement

Hype Engine is a self-hosted social publishing and workflow-automation
platform for teams that want to plan, schedule, and run social content without
giving up control of their data and infrastructure.

## Rationale and scope

- The description stays specific to the verified product capabilities in the
  README: publishing, scheduling, analytics, recurring content, and visual
  automation.
- The homepage directs evaluators to the existing live demo rather than a
  marketing page that is not maintained in this repository.
- The topics cover the product category, self-hosting and automation
  differentiators, and the verified implementation stack. They intentionally
  avoid unverified provider names, unsupported use cases, and comparative
  claims.
- The README opening now uses the same positioning statement, so a visitor who
  arrives through GitHub search sees a consistent promise before evaluating the
  feature list or Docker quick start.
